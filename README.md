# andctl

Termial-based control and live monitoring for Android devices.

> **Status:** early WIP

## Requirements

- Node.js
- adb
- [scrcpy](https://github.com/Genymobile/scrcpy)

## Features

- Resource, network, and battery monitoring
- Screen on/off and reboot
- Device Information
- App management
- Screen mirroring and control via scrcpy
- Multi-device support
